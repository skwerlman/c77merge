# C77Merge Executables

- `merge`: Mounts or unmounts the OverlayFS view of the mod profile over the game directory
- `profile_from_downloads`: Generate a new `<profile>.toml` which includes all the mods in the Download folder of a game. Useful for setting up an initial mod profile
- `updatemods`: Update the mods in a profile

Currently, only `profile_from_downloads` is complete enough to use.
